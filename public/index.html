CLASSROOM HTTP LAB

Campus Help Desk

A student needs help. Their browser sends a request. Your Express server finds a route, does the work, and sends a response. Predict the status before pressing Send.

1. Choose a story

A “task” is one help request. Buttons only prepare requests; press Send to see a real server response.

2. Inspect the request

POST and PATCH send Content-Type: application/json. GET and DELETE send no body.

Ask the class: “What will the server send back?”

Teacher controls

Reset restores the three original requests. The 500 example deliberately throws an error. Memory also resets when you restart Node.
